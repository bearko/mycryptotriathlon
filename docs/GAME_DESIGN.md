# My Crypto Triathlon ゲーム設計

## 1. 一言でいうと

My Crypto Heroes のヒーロー 50 組が、陸・海・空の 3 種目を競うお祭りレース。
最初は予選も通れない。走るたびに手に入る CE でスキルツリーを育て、少しずつ先へ進む。

- 陸：50 組 → 上位 30 組が通過（見下ろし型。拾ったエクステンションが自動で戦う）
- 海：30 組 → 上位 10 組が通過（潜水。酸素が命。財宝を掘り出す）
- 空：10 組のバトルロワイヤル。最後の 1 組になるまで（奥へ進む 3D。エクステンションを売って戦闘機をチューニング）

1 チームは 3 人のリレー（陸・海・空を別のヒーローが担当）。エクステンションがバトン。

## 2. 遊びの芯（3 つの段階で目標が変わる）

1. **陸を通過するまで**：ひたすらゴールを目指す。走る → 予選落ち → スキルツリー → もう一度。
   「前より先まで行けた」が毎回の手応えになる。
2. **海を通過するまで**：陸とはまったく別の遊び（酸素の管理と発掘）で、同じく挑戦と強化をくり返す。
3. **空で 1 位を取るまで**：陸・海で集めた品を GUM に換え、戦闘機を組んで、少しでも長く生き残る。

## 3. レース中の共通ルール

| こと | ルール |
|---|---|
| HP が 0 | **気絶**（数秒）。アイコンと姿がグレーになり、時間がたつと立ち上がる。ゲームオーバーではない |
| 審判 | コース上に立っていて、**視界は円**で見える。関門の手前など、混み合う場所にいる |
| 反則 | 審判の円の中で、ライバルを**直接攻撃（ストライク）**すると反則ポイント。上限までたまると、その場で数秒静止 |
| 円の外 | 直接攻撃しても、おとがめなし。妨害は「どこでやるか」が駆け引き |
| 反則にならない妨害 | ダッシュの体当たり（押しのける）、アイテム（雷・おとり）、パッシブスキルの弱体、エネミーを引きつれて集団に飛びこむ |
| ライバルも同じ | 荒っぽいライバルは殴ってくる。審判の前でやれば、彼らも止められる |
| 実況 | 画面上部で、クリスくん（実況）とマインちゃん（解説）が、いま起きていることを伝える |

### パッシブスキル（原作の再現）

ヒーローのパッシブスキルは、原作の「発動条件」と「効果」を読み取って当てはめる（`scripts/sync-assets.mjs` の `parsePassive`）。
名前と説明文は原作のまま、発動時にカットインで出す。

| 原作の条件 | このゲームでの発動 |
|---|---|
| バトル開始時 | レース開始時 |
| 自身の HP が N% 未満（1 回だけ） | HP が N% を切ったとき（1 回だけ） |
| 自身が死亡した後（1 回だけ） | 気絶したとき。「復活」の効果なら、その場で即座に立ち上がる |
| 自身が Active Skill を使用した後 | エクステンションが攻撃したあと（確率・間隔あり） |
| Active Skill でダメージを受けた後 | ダメージを受けたあと |
| そのほか | 一定時間ごと |

| 原作の効果 | このゲームでの効果 |
|---|---|
| PHY / INT アップ | 一定時間、威力アップ |
| AGI アップ | 一定時間、速さアップ |
| 敵のステータスダウン・睡眠など | まわりのエネミーを鈍らせる／止める。近くのライバルの足も鈍る（反則ではない） |
| 敵にダメージ | まわりのエネミーへの範囲攻撃、またはいちばん強い相手への一撃 |
| 回復・バリア・デコイ | 回復・しばらく無敵・しばらくエネミーに狙われない |
| 復活 | 気絶から即復帰 |

## 4. 陸

- 右へ走ってゴールへ。コース上のエクステンションを拾うと、自動で攻撃する（同じシリーズを拾うと Lv アップ）。ライバルも拾う。
- 関門が 3 つ。番人は倒せない。**自分が規定のダメージを与える**と、自分だけ通れる（火力がそのまま通過タイムになる）。
- 30 組がゴールした時点で締め切り。間に合わなければ、その場で予選落ち。
- 操作：移動／A＝ダッシュ（体当たり）／B＝ストライク（直接攻撃）。
- ライバル 49 組は実際にコースを走る。画面の近くではエネミーに絡まれ、気絶もする。遠くの組は簡略化して進める。
- 難度の目安（自動操縦での計測）：何も強化していないと 40〜50 位。数回ぶん育てると 20〜30 位。しっかり育てると上位。

## 5. 海（次の更新でレース化）

いまは 1 人で潜る形（酸素・銛・遺物で門を開ける・主を倒して秘宝）。
次の更新で 30 組が同時に潜り、秘宝を手にした先着 10 組が通過する形にする。

## 6. 空（次の更新でバトルロワイヤル化）

いまは 1 人で奥へ飛ぶ形。次の更新で、

- **チューニング**：陸・海で集めたエクステンションを売って GUM に換え、機体のパラメーターを強化したり、エクステンションを買い足したりする。
  この時間もレースに数えるので、早く決めた組から出撃できる。
- **バトルロワイヤル**：奥へ進む視点のまま 10 組で撃ち合う。ブーストとブレーキで前後の位置を取り合い、前にいる相手を撃つ。安全な空域はだんだん狭まる。

## 7. スキルツリー（周回で育てる）

- 通貨は 2 つ。**CE**（走った距離・関門・撃破・順位で毎回もらえる）と、**メダル**（はじめての達成ごとに 1 枚）。
- 枝は五勢力＋試練。

| 枝 | 役割 | 例 |
|---|---|---|
| 朱雀 | 攻め・エクステンション | 威力、攻撃間隔、最初の品の Lv、**新しい種類の解禁**（魔法・周回・突進・波動）、エピック／レジェンダリーの解禁、枠の追加 |
| 青龍 | 速さ | 足の速さ、ダッシュ、ロケットスタート、スリップストリーム、**ダッシュパネルの設置** |
| 玄武 | 守り・不屈 | HP、回復、気絶時間、復活時の HP、被ダメージ、パッシブスキルの発動率 |
| 白虎 | 駆け引き・妨害 | ストライク、体当たり、反則の上限、静止時間、**アイテムボックスの設置** |
| 黄竜 | 賞金・補給 | CE、チーム Lv、吸い寄せ、落ちている品の数、レアリティ |
| 試練 | あえて難しくする | エネミーの HP・数、コースの長さ、ライバルの速さ。かわりに報酬が増え、その先に強いパネルがある |

- 金の丸枠＝ゲームに新しい要素を足すパネル。同じ陸でも、解禁の前後で別の遊びになる。
- 赤の点線＝試練。自分で難度を上げて、報酬と、その先のパネルを取りにいく。
- まだ届かないパネルは「？」で見える（1 つ先まで）。
- 設計の考え方：1 回が短い／最初の数個はすぐ買える／通貨を分けて奥の枝に鍵をかける／新要素の解禁を道の途中に置く／難度を上げる選択に見返りをつける。
