# My Crypto Triathlon ゲーム設計

## 1. 一言でいうと

My Crypto Heroes のヒーロー 50 組が、陸・海・空の 3 種目を競うお祭りレース。
最初は予選も通れない。走るたびに手に入る CE でスキルツリーを育て、少しずつ先へ進む。

- 陸：50 組 → 上位 30 組が通過（見下ろし型。拾ったエクステンションが自動で戦う）
- 海：30 組 → 上位 10 組が通過（潜水。酸素が命。財宝を掘り出す）
- 空：10 組のバトルロワイヤル。最後の 1 組になるまで（奥へ進む 3D。エクステンションを売って戦闘機をチューニング）

1 チームは 3 人のリレー（陸・海・空を別のヒーローが担当）。エクステンションがバトン。

## 2. 遊びの芯（3 つの段階で目標が変わる）

1. **陸を通過するまで**：ひたすらゴールを目指す。走る → 予選落ち → スキルツリー → もう一度。
   「前より先まで行けた」が毎回の手応えになる。
2. **海を通過するまで**：陸とはまったく別の遊び（酸素の管理と発掘）で、同じく挑戦と強化をくり返す。
3. **空で 1 位を取るまで**：陸・海で集めた品を GUM に換え、戦闘機を組んで、少しでも長く生き残る。

## 3. レース中の共通ルール

| こと | ルール |
|---|---|
| HP が 0 | **気絶**（数秒）。アイコンと姿がグレーになり、時間がたつと立ち上がる。ゲームオーバーではない |
| 審判 | コース上に立っていて、**視界は円**で見える。関門の手前など、混み合う場所にいる |
| 反則 | 審判の円の中で、ライバルを**直接攻撃（ストライク）**すると反則ポイント。上限までたまると、その場で数秒静止 |
| 円の外 | 直接攻撃しても、おとがめなし。妨害は「どこでやるか」が駆け引き |
| 反則にならない妨害 | ダッシュの体当たり（押しのける）、アイテム（雷・おとり）、パッシブスキルの弱体、エネミーを引きつれて集団に飛びこむ |
| ライバルも同じ | 荒っぽいライバルは殴ってくる。審判の前でやれば、彼らも止められる |
| 実況 | 画面上部で、クリスくん（実況）とマインちゃん（解説）が、いま起きていることを伝える |

### パッシブスキル（原作の再現）

ヒーローのパッシブスキルは、原作の「発動条件」と「効果」を読み取って当てはめる（`scripts/sync-assets.mjs` の `parsePassive`）。
名前と説明文は原作のまま、発動時にカットインで出す。

| 原作の条件 | このゲームでの発動 |
|---|---|
| バトル開始時 | レース開始時 |
| 自身の HP が N% 未満（1 回だけ） | HP が N% を切ったとき（1 回だけ） |
| 自身が死亡した後（1 回だけ） | 気絶したとき。「復活」の効果なら、その場で即座に立ち上がる |
| 自身が Active Skill を使用した後 | エクステンションが攻撃したあと（確率・間隔あり） |
| Active Skill でダメージを受けた後 | ダメージを受けたあと |
| そのほか | 一定時間ごと |

| 原作の効果 | このゲームでの効果 |
|---|---|
| PHY / INT アップ | 一定時間、威力アップ |
| AGI アップ | 一定時間、速さアップ |
| 敵のステータスダウン・睡眠など | まわりのエネミーを鈍らせる／止める。近くのライバルの足も鈍る（反則ではない） |
| 敵にダメージ | まわりのエネミーへの範囲攻撃、またはいちばん強い相手への一撃 |
| 回復・バリア・デコイ | 回復・しばらく無敵・しばらくエネミーに狙われない |
| 復活 | 気絶から即復帰 |

## 4. 陸

- **前へは自動で走る**。プレイヤーは上下に動く（うしろに倒すと少しゆるめられる）。**関門の手前だけは自動前進が止まり、上下左右に自由に動いて番人に近づける**。A＝ダッシュ（体当たり）、B＝ストライク（直接攻撃）。
- エネミーを倒すと**経験**と **GUM** が落ちる。経験がたまるとレベルアップし、**3 枚のカードから 1 つ**選ぶ（選ぶあいだ、レースは止まる）。
  - カードは武器 10 種と強化 11 種、それぞれ Lv5 まで。形と数値は MyCrypto シリーズの姉妹作のレベルアップに合わせてある（`src/game/roster.ts`）。
  - 武器：ブレード（近くを回る刃）／リボルバー（扇状の弾）／ナイフ（ななめ 4 方向）／マレット（でたらめに投げる）／ブック（回って守る）／ホーキ（追いかけて貫く）／手裏剣（3 連）／パロット（頭上から）／レーザーガン（貫く光線）／雪だるま（置いて爆ぜる）
  - 強化：アーマー（最大 HP）／ブーツ（速さ）／りんご（威力）／ラーメン（回復）／ホース（攻撃間隔）／シールド（被ダメージ）／オリフラム（弾数）／標本（範囲）／グンバイ（貫通）／ギョク（引き寄せ）／クラウン（経験と GUM）
  - はじめに出るのは武器 4 種と強化 3 種。残りはスキルツリーで解禁する。持てる種類・育てられる Lv の上限もツリーで伸びる。
- **宝箱パネル**は、コースを横切る縦一列（6 枚）で並び、帯で目立たせる。取られたパネルは 5 秒で戻る。踏むと、**お助けエクステンション**（上の武器・強化とは別枠）が手に入る。右上に 2 つまで持てて、好きなときに使う（タップ、または 1・2 キー）。
  - **順位が低いほど強いものが出る**。
  - ペガサス（加速＋無敵）／パンジャンドラム（前へ転がり、当たったライバルを気絶）／ゴブレット（回復）／ネズミ捕り（うしろに仕掛ける）／こけし（エネミーに狙われない）／鏡（妨害をはね返す）／御札（雷で前の全員の足を止める）／ライドラゴン（猛スピードで飛ぶ）
  - はじめは 3 種。残りと、効果の強化・3 つ目の枠・パネルの増設はスキルツリーで。
  - ライバルも拾って使う。お助けエクステンションでの妨害は、審判の前でも反則にならない。
- 関門が 3 つ。番人は倒せない。**自分が規定のダメージを与える**と、自分だけ通れる（通過すると、カードを 1 枚もらえる）。
- **順位が決まるのはゴールライン**。最後の番人を抜けたあと、ゴールラインまでの直線でも順位は入れ替わる。
- ゴールすると、順位を大きく出したまま、ヒーローはゴールの先を走り続ける。「次のステージへ進む」を押すと次へ。
- レベルアップのカードは、**ボタンから手をはなして少し待つまで選べない**（連打での押し間違いを防ぐ）。
- 30 組がゴールした時点で締め切り。間に合わなければ、その場で予選落ち。
- ライバル 49 組は実際にコースを走る。画面の近くではエネミーに絡まれ、気絶もする。遠くの組は簡略化して進める。
- GUM は、空のチューニング（次の更新）で使う。
- 難度の目安（自動操縦での計測）：何も強化していないと 30〜45 位。数回ぶん育てると 30 位前後。中盤まで育てると 20 位台、しっかり育てると上位。

## 5. 海（30 組 → 先着 10 組）

- 30 組が同時に潜る。最深部の秘宝は 10 個だけで、掘り出した順に通過が決まる。10 個がなくなった時点で締め切り。
- **酸素が命**。つねに減り、切れると数秒の気絶（その場で起き上がる）。噴気孔の泡と、遺物を掘り出したときに回復する。
- 深さごとに門が 3 つ。**その深さの遺物を自分で掘り出した人だけ**が通れる（ほかの人が掘っても自分の門は開かない）。
- 発掘は、そばにいれば自動で進む。**攻撃を受けると発掘はやり直し**。ここが妨害のしどころ。
- A＝銛。エネミー用だが、ライバルに当たると直接攻撃になる。遺物と秘宝のそばには審判がいて、円の中で当てると反則。
- 最深部の「深海の主」は倒せない。弾と突進をかわしながら秘宝を掘る。
- 陸で育てた武器・強化はそのまま持ちこむ。宝箱と遺物で、カードをもう 1 枚引ける。
- ライバルは、画面の近くでは壁やエネミーの中を実際に泳ぐ。遠くの組は簡略化して進め、トラブルは確率で起こす。
- スキルツリー（青龍の先）：発掘の速さ、酸素の減り、噴気孔の回復、銛。
- 難度の目安（自動操縦。噴気孔を使わないので、人より気絶が多い）：陸を抜けたばかりで 14〜16 位、海の枝を少し育てて 9〜14 位、しっかり育てると上位。

## 6. 空（次の更新でバトルロワイヤル化）

いまは 1 人で奥へ飛ぶ形。次の更新で、

- **チューニング**：陸・海で集めたエクステンションを売って GUM に換え、機体のパラメーターを強化したり、エクステンションを買い足したりする。
  この時間もレースに数えるので、早く決めた組から出撃できる。
- **バトルロワイヤル**：奥へ進む視点のまま 10 組で撃ち合う。ブーストとブレーキで前後の位置を取り合い、前にいる相手を撃つ。安全な空域はだんだん狭まる。

## 7. スキルツリー（周回で育てる）

- 通貨は 2 つ。**CE**（走った距離・関門・撃破・順位で毎回もらえる）と、**メダル**（はじめての達成ごとに 1 枚）。
- 枝は五勢力＋試練。

| 枝 | 役割 | 例 |
|---|---|---|
| 朱雀 | 攻め・エクステンション | 威力、攻撃間隔、最初の品の Lv、**武器の解禁**（ブック・手裏剣・ホーキ・パロット・レーザーガン・雪だるま）、Lv4／Lv5 の解禁、枠の追加 |
| 青龍 | 速さ | 足の速さ、ダッシュ、ロケットスタート、スリップストリーム、**ダッシュパネルの設置** |
| 玄武 | 守り・不屈 | HP、回復、気絶時間、復活時の HP、被ダメージ、パッシブスキルの発動率 |
| 白虎 | 駆け引き・妨害 | ストライク、体当たり、反則の上限、静止時間、**お助けエクステンションの追加と強化**、宝箱パネルの増設 |
| 黄竜 | 賞金・経験 | CE、経験、GUM、吸い寄せ、カードの引き直し、強化（ギョク・クラウン）の解禁 |
| 試練 | あえて難しくする | エネミーの HP・数、コースの長さ、ライバルの速さ。かわりに報酬が増え、その先に強いパネルがある |

- 金の丸枠＝ゲームに新しい要素を足すパネル。同じ陸でも、解禁の前後で別の遊びになる。
- 赤の点線＝試練。自分で難度を上げて、報酬と、その先のパネルを取りにいく。
- まだ届かないパネルは「？」で見える（1 つ先まで）。
- 設計の考え方：1 回が短い／最初の数個はすぐ買える／通貨を分けて奥の枝に鍵をかける／新要素の解禁を道の途中に置く／難度を上げる選択に見返りをつける。
